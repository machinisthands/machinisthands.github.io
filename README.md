# machinisthands.github.io
Root site for **machinisthands.github.io**.

- `ads.txt` – must live at the domain root for Google AdSense.
- `index.html` – the front page: the Mechanical Workshop home page (job cards by semester). Its pictures, styles and scripts load from the [mechanicalworkshop](https://github.com/machinisthands/mechanicalworkshop) site, so change the look there.
- `robots.txt`, `sitemap.xml`, `favicon.ico` – root-level files browsers and search engines look for.
